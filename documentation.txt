5. CSS Manipulation

CSS change

$("#demo").css("color","red");

In jQuery, CSS Manipulation means changing CSS styles using jQuery methods.

Main jQuery CSS Methods
1. css() Method

Used to get or set CSS properties.

Syntax
$(selector).css("property","value");
Example
<!DOCTYPE html>
<html>
<head>
<script src="https://code.jquery.com/jquery-3.7.1.min.js"></script>
</head>
<body>

<p id="demo">Hello jQuery</p>

<button id="btn">Change CSS</button>

<script>
$("#btn").click(function(){

    $("#demo").css("color", "red");
    $("#demo").css("font-size", "30px");
    $("#demo").css("background", "yellow");

});
</script>

</body>
</html>
Multiple CSS Properties
$("#demo").css({
    "color":"white",
    "background":"black",
    "font-size":"25px"
});
Get CSS Value
var color = $("#demo").css("color");

alert(color);
Width and Height Manipulation
Set Width
$("#box").width("300px");
Get Width
var w = $("#box").width();
Add / Remove CSS Class
addClass()
$("#demo").addClass("myclass");
removeClass()
$("#demo").removeClass("myclass");
toggleClass()
$("#demo").toggleClass("myclass");
Full Example
<!DOCTYPE html>
<html>
<head>

<style>
.red{
    color:white;
    background:red;
    padding:20px;
}
</style>

<script src="https://code.jquery.com/jquery-3.7.1.min.js"></script>
</head>
<body>

<p id="text">Learning jQuery CSS</p>

<button id="add">Add Class</button>
<button id="remove">Remove Class</button>
<button id="toggle">Toggle Class</button>

<script>

$("#add").click(function(){
    $("#text").addClass("red");
});

$("#remove").click(function(){
    $("#text").removeClass("red");
});

$("#toggle").click(function(){
    $("#text").toggleClass("red");
});

</script>

</body>
</html>

6. AJAX

Page reload without server data load 

$.ajax({
   url:"data.php",
   success:function(data){
      $("#result").html(data);
   }
});

Common AJAX Options
